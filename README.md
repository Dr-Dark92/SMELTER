# SMELTER

Private monorepo for local tools, agents, automation, Studio and future projects.

## Structure
- `tools/`: bootstraps, reverse engineering, asset processing and shared pipeline
- `agents/`: skill contracts, prompts and non-secret configurations
- `studio/`: web frontend and backend scaffolding
- `automation/`: workflows, GitHub sync and handovers
- `docs/`: architecture
- `projects/`: reserved; no project directories created

## Principles
Local-first execution, reproducible automation, validated results, explicit publishing approval. Never commit original game binaries, extracted copyrighted assets, credentials or generated build outputs.

This commit establishes the structure only; tool implementations and integrations are not yet installed.
