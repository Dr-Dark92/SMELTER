# SMELTER

Private monorepo for local tooling, automation, agent skills, the Studio interface, and future projects.

Projects are intentionally empty until individually initialized.

## Layout

- `tools/` — Windows bootstraps, reverse engineering, asset processing, shared pipeline
- `agents/` — reusable skill contracts, prompts, configurations
- `studio/` — frontend and backend scaffolding
- `automation/` — workflows, GitHub synchronization, handovers
- `docs/` — architecture and engineering notes
- `projects/` — reserved for future projects; no projects created yet

## Principles

Local-first; deterministic automation; explicit approval for publishing; evidence-backed reports; no original game binaries, extracted copyrighted assets, secrets, or large generated outputs in Git.
